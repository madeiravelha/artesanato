# Madeira Velha - Artesanato e Souvenirs

Código-fonte completo do site institucional responsivo e de alto desempenho projetado para a empresa **Madeira Velha Artesanato e Souvenirs**, com foco em atração de tráfego orgânico (SEO Local) e conversão em visitas presenciais, ligações telefônicas e contatos via WhatsApp.

## 🚀 Arquitetura e Performance Tecnológica

Este projeto foi construído em estrita conformidade com os requisitos de desempenho e boas práticas estipulados pelo ecossistema **Google PageSpeed**.
*   **HTML5 Semântico:** Uso preciso de marcas estruturais (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer >`) para correta interpretação de robôs de busca.
*   **CSS3 Vanilla Puro:** Sem frameworks ou dependências pesadas, minimizando o tempo de bloqueio de renderização (Render-Blocking Resources).
*   **JavaScript Nativo:** Implementação enxuta de interatividades como menu móvel, lightbox de imagens e sanfonas de FAQ, garantindo excelente First Input Delay (FID) e Interaction to Next Paint (INP).
*   **Imagens Próxima Geração (WebP):** Com atributos estruturais de tamanho (`width` e `height`) e carregamento adiado nativo (`loading="lazy"`) para otimização de Cumulative Layout Shift (CLS) e Largest Contentful Paint (LCP).

## 📊 Estratégia de SEO e Dados Estruturados

*   **Conteúdo Long-Form:** Home projetada estrategicamente com densidade semântica perfeita para os termos-chave regionais da rota dos cânions e balonismo de Praia Grande e São João do Sul.
*   **Metadados:** Arquitetura limpa de tags canônicas, títulos e descrições exclusivas para cada página, acompanhadas de protocolos OpenGraph e Twitter Cards.
*   **Structured Data JSON-LD:** Grafo semanticamente integrado injetado na raiz do cabeçalho mapeando os esquemas organizacionais, de avaliações locais, perguntas frequentes e breadcrumbs.

## 🛠️ Como Clonar e Hospedar

O projeto foi preparado especificamente para o ecossistema de servidores estáticos do **GitHub Pages**.

1. Crie um novo repositório público no seu GitHub chamado `madeira-velha`.
2. Clone os arquivos mantendo rigorosamente a árvore de diretórios apresentada na documentação de entrega.
3. Realize o push para a branch `main`.
4. Ative as configurações do **GitHub Pages** nas opções do seu repositório apontando para a pasta root `/`.
